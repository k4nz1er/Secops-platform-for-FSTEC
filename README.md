Веб-платформа для автоматизации обработки бюллетеней безопасности (ФСТЭК / НКЦКИ), учёта уязвимостей (БДУ / CVE) и управления индикаторами компрометации (IOC).

## Для чего нужен

* **Парсинг документов с OCR:** `PDF` (включая сканы), `DOCX`, `DOC`, `RTF`, `TXT`, `EML`, `MSG`.
* **Режимы загрузки:** раздельный парсинг («Только БДУ», «Только IOC», «Авто»).
* **Реестр уязвимостей:** группировка по номерам входящих писем, обогащение данными БДУ ФСТЭК, быстрая смена статусов, фильтрация и экспорт в CSV.
* **Реестр IOC:** автоматический refang (`hxxp`, `[.]`), фильтрация легитимных доменов, управление статусами и выгрузка блоклиста (`ioc_blocklist.txt`).
* **Канбан-доска:** отслеживание задач, сроков и прогресса отработки.

## Стек

* **Backend:** FastAPI, SQLAlchemy, Celery, httpx
* **Frontend:** React, TypeScript, Vite, Ant Design (кастомная тема Cyberpunk HUD)
* **Инфраструктура:** PostgreSQL, Redis, RabbitMQ, Nginx, Docker Compose

## Быстрый старт

```bash
git clone [https://github.com/k4nz1er/secops-platform.git](https://github.com/k4nz1er/secops-platform.git)
cd secops-platform
cp .env.example .env
docker compose up -d --build
```

После запуска интерфейс доступен по адресу: `http://localhost/`.

В текущей версии конфиг авторизации переведен в локальный режим для развертывания в изолированном контуре.
